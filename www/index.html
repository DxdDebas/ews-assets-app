Mobile & Web Deployment

Install as Android App (APK / PWA) & Source Bundle

Option 1: Instant Mobile App Install (PWA — Zero Build Required)

Open this Web App in Chrome on Android (or Safari on iOS), tap the browser menu (⋮) and choose "Add to Home Screen" / "Install App". It runs full-screen offline with local storage and generates .docx and .xlsx files directly on your phone.

Option 2: Download Complete Android Studio / Capacitor APK Project (.ZIP)

Click below to generate and download a ready-to-compile Android APK project (EWS_Android_APK_Project.zip) containing:

  • app/src/main/AndroidManifest.xml & MainActivity.java (Native Android WebView with binary Blob downloader for .docx & .xlsx)
  • capacitor.config.json & package.json for npx cap build android
  • .github/workflows/build-apk.yml — Push to any GitHub repo to automatically compile and download a signed app-debug.apk in the cloud!
